# کنترل مرغداری (اپ اندروید)

اپ با پیامک به دستگاه آردوینو فرمان می‌دهد و پاسخ را می‌خواند.

## ساخت APK
1. این پوشه را در یک مخزن گیت‌هاب بریزید (شاخه‌ی main).
2. تب Actions را باز کنید؛ ساخت خودکار اجرا می‌شود (یا Run workflow).
3. APK را از Releases (نسخه‌ی latest) دانلود و نصب کنید.

## راه‌اندازی
شماره‌ی سیم‌کارت دستگاه و رمز (پیش‌فرض 1234) را ذخیره کنید. اولین بار اجازه‌ی پیامک را بدهید.
